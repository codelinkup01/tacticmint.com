# TacticMint Website

Ready-to-publish static website for TacticMint.com.

## Included
- Responsive single-page website
- TacticMint visual identity
- Mobile navigation
- SEO metadata
- Open Graph metadata
- Newsletter UI
- Facebook / LinkedIn / YouTube / X / Instagram / TikTok links
- Sections for Intelligence, Guides, Tools and Experiments

## Important
The newsletter form opens the visitor email app with a subscription request addressed to hello@tacticmint.com. Visitors must send the email. The form does not automatically store subscribers or deliver newsletters.

## Deployment
Upload the contents of this folder to any static host such as Cloudflare Pages, Vercel, Netlify, GitHub Pages, or your existing hosting provider, then point tacticmint.com to the deployed site.
